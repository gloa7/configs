Shortcuts:
CTRL+ w, w -> Switch nvim tree window
CTRL + ] -> Set new sub directory as root
CTRL + \ -> Open Terminal
:bd -> Close file leaving window open
a -> Create new file/folder in nvim-tree view, append "/" at the end for a directory


Tips:
1. Open terminal after a file has been opened next to tree view, or else it has the potential to open in 3 columns
